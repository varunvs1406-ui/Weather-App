# Weather App

A simple weather application built using HTML, CSS, and JavaScript.

## Features

- Search weather by city
- Shows temperature in Celsius
- Displays humidity
- Displays wind speed
- Dynamic weather icons

## Technologies Used

- HTML
- CSS
- JavaScript
- OpenWeather API

## How to Run

1. Clone the repository
2. Open index.html in a browser
3. Search for a city
